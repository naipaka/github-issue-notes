# Chrome Web Store Description

## Short Description (for manifest.json, max 132 chars)

Add personal notes to GitHub issues and PRs

## Detailed Description (copy below for store)

```
Ever subscribed to an open source issue or PR and later forgot why? This extension lets you add personal notes to each issue and PR, so you always remember the context.

Add personal notes to any GitHub Issue or Pull Request page. Your notes are saved to your private GitHub Gist and synced across all your devices.

Features:
• Personal Notes on Issues/PRs - Add private notes directly on GitHub Issue and PR pages
• Private Gist Storage - Notes are saved to your own GitHub Private Gist (only you can access)
• Auto-save - Notes are automatically saved as you type
• Dark Mode Support - Seamlessly adapts to GitHub's dark mode
• Cross-device Sync - Access your notes from any device via Gist

How It Works:
1. Get a GitHub Personal Access Token with Gist permissions
2. Enter your token in the extension settings
3. Click "Connect Gist" to set up storage
4. Navigate to any GitHub Issue or PR and start taking notes!

Your notes appear in the sidebar, right below the Notifications section.

Privacy:
• Your Personal Access Token is stored locally in your browser
• Notes are stored in YOUR private GitHub Gist (only you can access)
• No analytics, no tracking, no data collection
• The extension only communicates with GitHub's official API

Permissions:
• Storage: Save your settings locally
• api.github.com: Read and write notes to your private Gist

Open Source:
This extension is open source. View the code and report issues on GitHub:
https://github.com/naipaka/github-issue-notes
```
